# homebrew-strata

Homebrew tap for [strata](https://github.com/D1srupt3d/strata), a layered dotfiles manager.

```sh
brew install D1srupt3d/strata/strata
```

Or tap once and use the short name:

```sh
brew tap D1srupt3d/strata
brew install strata
```

Update with `brew upgrade strata`, remove with `brew uninstall strata`
(then `strata uninstall` first if you also want its config and state gone).

## How this repo works

`Casks/strata.rb` is generated by GoReleaser on every strata release, so don't
edit it here; changes would be overwritten. Issues and pull requests go to
[strata](https://github.com/D1srupt3d/strata). The cask pins each release
archive's SHA-256, the same values listed in the release's signed `checksums.txt`.
